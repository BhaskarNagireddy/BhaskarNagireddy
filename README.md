## 🔄 CI/CD & Software Reliability

I’m particularly interested in development workflows where every code change is automatically validated before moving further through the delivery pipeline.

A typical workflow I work toward looks like:

`Code Change → Git Push / Merge Request → GitLab CI Trigger → Build → Unit Tests → Integration Tests → Security & Quality Checks → Review → Deployment`

I use automated testing and CI/CD checks to detect problems early, verify expected software behaviour, and improve **software reliability, maintainability and delivery confidence**.

I’m also interested in understanding why pipelines fail — whether the issue originates from **application code, configuration, dependencies, test failures, security policies or the execution environment** — and using that information to systematically troubleshoot and improve the development workflow.
